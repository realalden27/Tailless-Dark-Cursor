# Tailless Dark Cursor

A dark cursor scheme for Windows. The package includes standard pointer cursors
and animated busy cursors, and uses the name **Tailless Dark Cursor by
RealAlden27** in Windows.

## Install

1. Download or clone this repository and extract it if it is an archive.
2. In File Explorer, right-click `Install.inf` and select **Install**. Approve
   the Windows prompt if one appears.
3. If the scheme does not appear immediately, open **Mouse Properties** >
   **Pointers**, select **Tailless Dark Cursor by RealAlden27** from the
   **Scheme** list, and select **Apply**.

The installer copies the cursor files into a `Tailless Dark Cursor` folder
under the Windows directory and registers the scheme for the current Windows
user. Sign out and back in, or restart Windows, if some applications continue
to show the previous cursors.

## Included cursors

| File | Pointer |
| --- | --- |
| `arrow.cur` | Normal select |
| `help.cur` | Help select |
| `appstarting.ani` | Working in background |
| `wait.ani` | Busy |
| `crosshair.cur` | Precision select |
| `ibeam.cur` | Text select |
| `nwpen.cur` | Handwriting |
| `no.cur` | Unavailable |
| `sizens.cur` | Vertical resize |
| `sizewe.cur` | Horizontal resize |
| `sizenwse.cur` | Diagonal resize (NW-SE) |
| `sizenesw.cur` | Diagonal resize (NE-SW) |
| `sizeall.cur` | Move |
| `uparrow.cur` | Alternate select |
| `hand.cur` | Link select |
| `person.cur` | Person select |
| `pin.cur` | Location select |

## Uninstall or switch back

Open **Mouse Properties** > **Pointers**, choose the **Windows Default**
scheme, and select **Apply**. Changing schemes stops using this theme, but does
not remove the cursor files copied under the Windows directory.

## Compatibility

This package is intended for Windows. The `.cur` files are static cursors and
the `.ani` files are animated cursors.
